# Changelog

Todas as mudancas relevantes deste projeto seguem versionamento semantico.

## 1.0.0

- API declarativa com `defineComponent` e `createApp`.
- Props tipadas, defaults, validadores, eventos e injecao de servicos por alias.
- Bootstrap automatico, seguro e executado uma unica vez.
- CLI para criar, sincronizar, validar e empacotar componentes.
- Catalogo automatico de imports e metadados HTML para o VS Code.
- Extensao com navegacao, autocomplete, hover, diagnosticos e rename.
- Build minificado com sourcemap, templates/CSS incorporados e orcamentos.
- Batching de `$setState`, metricas de runtime e benchmark contra AngularJS nativo.
- CSS isolado opt-in, nonce CSP e harness oficial de testes.
- Compatibilidade mantida com as APIs `app`, `use`, `component` e `register` da serie 0.x.

## 0.5.0

- Build de producao, metricas e orcamentos de desempenho.

## 0.4.0

- Inteligencia semantica na extensao do VS Code.

## 0.3.0

- CLI, gerador e catalogo automatico.

## 0.2.0

- Primeira API declarativa independente do modulo AngularJS.

## 0.1.0

- Camada inicial sobre `module.component()`.
