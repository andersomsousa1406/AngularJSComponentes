API essencial

Tudo que um componente precisa.

Uma superficie pequena, previsivel e totalmente apoiada no ciclo de vida nativo do AngularJS.

props

Entradas tipadas

Defaults, validadores e bindings < @ = &.

state

Estado local

Objeto ou factory inicializada depois das props.

methods

Metodos ligados

this sempre aponta para o componente.

computed

Valores derivados

Getters enxutos, sem sincronizacao manual.

watch

Observadores seguros

Watchers removidos automaticamente no destroy.

hooks

Ciclo completo

Init, changes, post-link e destroy.
